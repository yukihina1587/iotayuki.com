学習の進め方

  1. Docker → コンテナ化・マルチステージビルドの実践
  2. Docker Compose → 本番グレードの複数コンテナ管理
  3. K8s基礎 → Pod・Deployment・Serviceの理解
  4. K8sネットワーク → Ingress・NetworkPolicyの設定
  5. Terraform → IaCの基礎とモジュール設計
  6. Terraform応用 → Workspace・Terragruntによる環境管理
  7. GitHub Actions → CI/CDパイプラインの構築

進捗チェックリスト

  • マルチステージビルドのDockerfileを書ける
  • Docker ComposeでヘルスチェックとVolume設定ができる
  • K8sのDeployment・Service・Ingressを設定できる
  • HPA（水平オートスケーリング）を設定できる
  • TerraformでEC2+ALB+RDSを構築できる
  • GitHub ActionsでCI/CDパイプラインを構築できる
