ガイドCOURSE GUIDE

この教材で学ぶこと 学ぶ順番と、このコースで身につく力を確認します。

プログラミング学習ロードマップ

概要

未経験から始め、Web、automation、backend、test、設計へ段階的に進みます。すべての言語を同時に暗記するのではなく、共通する考え方を学び、目的に応じて道具を選びます。

入口を選ぶ

  • 完全な未経験者: STEP 01から順番に進む
  • Webページを作ったことがある: Git、JavaScript、TypeScriptを確認する
  • serverやautomationが目的: Programming基礎の後、BashまたはPythonへ進む
  • Java等の経験者: 必要なlanguage lessonを飛ばし、test、API、設計へ進む

Phase 1 — はじめて

  1. コンピュータとプログラム入門
  2. 開発環境とターミナル入門
  3. プログラミング基礎

この段階では、用語の暗記より「入力・処理・出力へ分け、小さく実行する」ことを重視します。

Phase 2 — 基礎

  1. GitとGitHub入門
  2. HTMLとCSS入門
  3. JavaScript入門
  4. Bash入門
  5. Python入門
  6. Java入門

Web pathならHTML/CSS → JavaScript、automation pathならBash → Pythonを中心に進めます。Javaは静的型付けとobject-oriented designを学ぶ別の入口です。

Phase 3 — 実践

  1. TypeScript入門
  2. Bashシェルスクリプト実践
  3. PythonのテストとCLI
  4. データ構造とアルゴリズム入門
  5. テストとデバッグ

Phase 4 — 発展

  1. HTTP API設計
  2. 設計とリファクタリング
  3. Python実践 — Kotlinエンジニア向け

最後は一つの作品を完成させます。README、実行手順、入力検証、test、制約、rollback方法までを成果物に含めます。

到達チェックリスト

  • programを入力・処理・出力へ分けられる
  • Gitで差分を確認し、目的ごとにcommitできる
  • semantic HTML、responsive CSS、JavaScriptで小さなWebページを作れる
  • BashまたはPythonで入力検証付きのautomation toolを作れる
  • JavaScriptとTypeScript、またはPythonとJavaの性質を比較できる
  • 正常系・境界値・異常系のtestを書ける
  • HTTP APIの成功・失敗・認証認可・冪等性を設計できる
  • testを保ちながら責務と依存関係をrefactorできる
