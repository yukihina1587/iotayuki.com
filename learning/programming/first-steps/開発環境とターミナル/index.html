はじめてLESSON 02

この教材で学ぶこと 安全な練習場所を作り、terminalとcommandの基本を学びます。

開発環境とターミナル入門

対象読者: ファイル操作やコマンド入力に不安がある初学者。

この教材でできるようになること

  • エディタ、ターミナル、シェル、ランタイムを区別できる
  • 作業用ディレクトリを作り、安全に移動できる
  • コマンドの「名前・オプション・引数」を読み分けられる
  • エラーを再現できる形で記録できる

1. 開発に使う四つの道具

道具 役割
エディタ ソースコードを書く
ターミナル 文字でコンピュータを操作する画面
シェル 入力したコマンドを解釈して実行する
ランタイム／処理系 PythonやJavaScriptなどのコードを実行する

ターミナルとシェルは同じものではありません。ターミナルは入出力の窓口で、その中でBash、zsh、PowerShellなどのシェルが動きます。

2. 練習場所を作る

以下はBashやzshでの例です。WindowsのPowerShellでは一部のコマンドが異なります。

mkdir -p learning-programming/hello
cd learning-programming/hello
pwd
  • mkdir: ディレクトリを作るコマンド
  • -p: 親ディレクトリも必要なら作るオプション
  • learning-programming/hello: 操作対象となる引数

現在位置を確認せず削除や上書きをしない習慣が重要です。

3. ファイルを観察する

printf 'print("Hello")\n' > hello.py
ls -la
cat hello.py
python hello.py

>は標準出力をファイルへ上書きします。既存内容を失うため、意味を理解するまでは練習用ディレクトリだけで使いましょう。

4. 相対パスを読む

.
├── hello.py
└── notes/
    └── memo.txt

notes/memo.txtは現在位置から見た相対パス、..は一つ上、.は現在位置です。

cd notes
pwd
cd ..

5. コマンドを調べる

暗記より、調べ方を身につけます。

command --help
man command
type command

実行前に、対象、上書きの有無、必要な権限を確認します。インターネット上のコマンドを意味不明のまま貼り付けないでください。

6. エラーを記録する

質問や調査に必要なのは「動きません」ではなく、再現できる情報です。

目的:
実行したコマンド:
期待した結果:
実際の結果:
エラーメッセージ全文:
OS・処理系の版:
直前に変更したこと:

ただし、トークン、パスワード、個人情報、社内URLは共有前に必ず伏せます。

演習: 練習プロジェクトを作る

  1. learning-programming/profileを作る
  2. その中へREADME.mdを作る
  3. READMEへ「学びたいこと」を一行書く
  4. 現在位置とファイル一覧を表示する
  5. 一つ上へ戻る

確認例

mkdir -p learning-programming/profile
cd learning-programming/profile
printf '# 学びたいこと\nWebアプリを作れるようになる。\n' > README.md
pwd
ls -la
cat README.md
cd ..

理解チェック

  • ターミナルとシェルの違いを説明できる
  • 実行前後にpwdとlsで対象を確認できる
  • コマンドのオプションと引数を区別できる
  • 秘密情報を含めずにエラーを記録できる
