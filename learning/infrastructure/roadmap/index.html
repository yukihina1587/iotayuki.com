学習の進め方

  1. Linux実践 → 日常コマンドとプロセス管理の習得
  2. パフォーマンスチューニング → 実務でのサーバー最適化
  3. TCP/IP → ネットワーク通信の仕組みを応用情報レベルで理解
  4. LB・プロキシ → クラウド設計に欠かせないL4/L7の知識

進捗チェックリスト

  • psコマンドでCPU・メモリ使用量を分析できる
  • tcpdump・ssでネットワーク通信を調査できる
  • TCPの3ウェイハンドシェイクを説明できる
  • L4/L7ロードバランサーの違いを説明できる
  • Nginxのリバースプロキシ設定を書ける
