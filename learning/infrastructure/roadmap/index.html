ガイドCOURSE GUIDE

この教材で学ぶこと Linuxとネットワークを学ぶ全体像を確認します。

🌐 インフラ基礎 学習ロードマップ

概要

未経験者はserverと通信の全体像から始め、Linux と ネットワーク を観測しながら実践・応用レベルへ進みます。

最初の一歩

サーバーとネットワーク入門で、CPU・memory・storage、IP address・port・DNS・HTTPを一つのrequest経路として理解します。その後にLinuxとTCP/IPの詳細へ進みます。

学習の進め方

  1. サーバーとネットワーク入門 → requestが届くまでの全体像
  2. Linux実践 → 日常コマンドとプロセス管理の習得
  3. TCP/IP → ネットワーク通信の仕組みを詳細に理解
  4. LB・プロキシ → L4/L7と通信経路の設計
  5. パフォーマンスチューニング → 計測からbottleneckを特定

進捗チェックリスト

  • psコマンドでCPU・メモリ使用量を分析できる
  • tcpdump・ssでネットワーク通信を調査できる
  • TCPの3ウェイハンドシェイクを説明できる
  • L4/L7ロードバランサーの違いを説明できる
  • Nginxのリバースプロキシ設定を書ける
