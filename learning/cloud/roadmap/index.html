ガイドCOURSE GUIDE

この教材で学ぶこと AWS設計を段階的に学ぶルートを確認します。

☁️ クラウド（AWS）学習ロードマップ

概要

cloudを初めて学ぶ人はserviceの役割と責任境界から始め、AWSを中心に設計・運用・コスト最適化へ進みます。

最初の一歩

クラウド基礎で、compute・storage・network・database・identity、shared responsibility、availability、costを学びます。製品名を暗記する前に、要件をserviceの役割へ分解します。

学習の進め方

  1. クラウド基礎 → serviceの役割、責任、cost、availability
  2. SAA以上の設計 → Well-Architected・可用性設計の深掘り
  3. コンテナサービス → ECS Fargate vs EKS の使い分け
  4. サーバーレス → Lambda・API Gatewayによるイベント駆動設計
  5. データベース → RDS/Aurora/DynamoDBの選定基準と運用
  6. 静的サイト配信 → GitHub PagesとCloudflare Pagesの選定基準

進捗チェックリスト

  • Multi-AZ と Multi-Region の違いと使い分けを説明できる
  • ECS Fargate と EKS の選定基準を説明できる
  • Lambdaのコールドスタート対策を説明できる
  • Aurora と RDS の違いを説明できる
  • DynamoDBのキー設計（PK・SK・GSI）ができる
  • GitHub PagesとCloudflare Pagesを要件から選べる
