学習の進め方

  1. SAA以上の設計 → Well-Architected・可用性設計の深掘り
  2. コンテナサービス → ECS Fargate vs EKS の使い分け
  3. サーバーレス → Lambda・API Gatewayによるイベント駆動設計
  4. データベース → RDS/Aurora/DynamoDBの選定基準と運用

進捗チェックリスト

  • Multi-AZ と Multi-Region の違いと使い分けを説明できる
  • ECS Fargate と EKS の選定基準を説明できる
  • Lambdaのコールドスタート対策を説明できる
  • Aurora と RDS の違いを説明できる
  • DynamoDBのキー設計（PK・SK・GSI）ができる
